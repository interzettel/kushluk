# Evidence protocol

Stiprā-local companion reference, derived from the owner's uploaded Design Maturity Review v1.0.0 SKILL.md; the originally referenced document was not supplied. Use the original SKILL.md as authority. Do not attribute this material to the missing original reference.

Classify claims as observed, inferred, preference, unknown/untested, or not applicable. Cite a file, rendered screenshot, observed control state, test output, timestamped release, or direct link for consequential observations. A passing build is not a user acceptance test. No invented visual-regression pass, print proof or human study. Review desktop/mobile and a relevant edge state, and make new acceptance criteria falsifiable.
