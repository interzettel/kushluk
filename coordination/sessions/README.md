# Verified round receipts (not automatic chat logs)

No live three-peer round is recorded at creation. Create a dated subfolder **only after real events** have occurred. A receipt should contain the actual source commit, owning discussion issue, independently authored review comment URLs, each model/runner attribution, time, dissent, owner verdict if any, and test results. If a peer didn't respond, state `NO RESPONSE`; never synthesize a stand-in opinion.

Example future session directory: `coordination/sessions/2026-10-XX-r6-first-round/`.

**Public repo warning:** do not commit raw prompts containing private inboxes, personal subscriptions, non-shareable document contents, login info, A2A bearer tokens or private user data. Link sanitized public evidence and authorized private artifact paths only.
