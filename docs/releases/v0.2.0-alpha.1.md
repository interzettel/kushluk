# Kuşluk v0.2.0-alpha.1 — experimental developer preview

This is the first **experimental, GitHub-only source release** of Kuşluk, a local-first personal newspaper. **It is not a supported production application**, and should not be scheduled to print or email autonomously without the user's own testing and consent.

### What you can try

- Install the `0.2.0a1` pure-Python wheel or source archive in a fresh Python 3.11+ environment.
- Run `kushluk preview --output-dir ./sample-edition` to create a **fully fictional four-page** editorial sample without account connections, network requests, printing or emails.
- With separately installed and licensed PDF dependencies, optionally render the fictional preview as a four-page A4 PDF. Read the native font/Pango requirements before enabling PDF.
- Inspect the local setup, source permissions, A4 / US Letter options, and read-only morning status. These are experimental and not proof of any hardware behavior.

### Installation

Download `kushluk-0.2.0a1-py3-none-any.whl`, `kushluk-0.2.0a1.tar.gz`, and `SHA256SUMS.txt` from **this GitHub prerelease**. Verify checksums. Then, in a new virtual environment:

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install /absolute/path/to/kushluk-0.2.0a1-py3-none-any.whl
kushluk preview --output-dir ./sample-edition
```

Optional PDF support needs separately installed system libraries and fonts:
```bash
python -m pip install "/absolute/path/to/kushluk-0.2.0a1-py3-none-any.whl[pdf]"
kushluk preview --output-dir ./sample-pdf --pdf
```

**Do not run `pip install kushluk==0.2.0a1` from PyPI**: this project has not been published there.

### Distribution / licensing boundary

The GitHub assets contain Kuşluk's own **MIT-licensed Python source, HTML template, release docs, license and third-party notices**. No font files, Pango/Cairo/HarfBuzz/Fontconfig binaries, external article text, publisher photographs, personal data, or generated PDF files are included. Python dependencies are resolved **separately** through the reader's package manager; system libraries and fonts remain the reader's responsibility and subject to their respective licences. This limited source release is not a certification of native-binary or font redistribution rights.

### Important unverified areas

Physical A4/US Letter/A3 print acceptance; macOS/Linux unattended-host reliability and five consecutive mornings; first-reader and keyboard/screen-reader trial acceptance; actual email arrival; real-world source/content permissions; and native/font redistribution approval remain **unverified**. They must not be counted as passed release gates.

The trial build process and the release artifacts were checked through synthetic source/package tests. Passing CI cannot establish that a specific printer will produce four readable pages. Windows and full native distributions are not part of this alpha support claim.
