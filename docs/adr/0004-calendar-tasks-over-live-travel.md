# ADR 0004 — Calendar and tasks outrank live travel details

**Status:** Accepted

## Context

Calendar and task commitments are comparatively stable. Rail/air operational details can change rapidly.

## Decision

Printed space prioritises calendar and tasks over detailed live travel status.

Kushluk may print stable travel context and pointers to live apps, but should not pretend the morning sheet is authoritative for delays, gates, platforms, cancellations, or similar volatile data.

## Rationale

Static media should carry stable commitments; live apps should carry live operations.

## Consequences

Travel integrations are useful for context and delivery decisions, but detailed live travel status is not a dominant print requirement.
