## This is a ballot, not claimed consensus

ChatGPT researched candidate repositories and has recorded **provisional judgments** below. **Claude has not independently reviewed these candidates in this conversation and no real attributable Claude vote has been received**: its column is **PENDING**, never inferred agreement. Do not claim two-agent acceptance until a distinct review is actually posted with evidence links by Claude/authorized operator. User/founder may approve or reject after seeing both views, but cannot erase the reasons for dissent.

A repository license for software does not give permission to redistribute publisher text, someone else's photographs, fonts, or a reader's subscribed content. **No one may replace #38 policy, #4 rights checks, or security review with a majority vote.** Candidate `COPY` needs actual file-level license, revision SHA, exact copied file, notice path and founder authorization *before* merging. `INDEPENDENT IDEA` transfers a non-protectable functional concept via original work and regression tests, not modified copy/paste disguised as clean-room engineering; `OPTIONAL ADAPTER` requires opt-in and no core dependency.

Reviewer positions: `FOR` / `CONDITIONAL` / `AGAINST`, together with what would change that opinion.

### Independent-review handoff protocol

1. **ChatGPT** posts its evidence/rationale and proposed tests (the above is provisional). Each choice should include any **AGAINST** or **CONDITIONAL** points explicitly.
2. **Claude**, as a separate reviewer, is asked to examine the same linked public report, actual LICENSE files, source code and feature/roadmap constraints and post its **own** `R-ID | FOR/AGAINST/CONDITIONAL | evidence | disconfirming tests` records to [#88](https://github.com/interzettel/kushluk/issues/88). No automated direct inter-agent message is implied; @mentions cannot guarantee delivery without actually configured integration.
3. **Concordance:** agreement (same scoped transfer + conditions) can progress to implementation fixture, but not to actual copying or shipping without tests and owner sign-off. A disagreement stays **DISPUTED** and needs a dated counterexample, measured spike or founder decision, not silence.
4. **After resolution**, record final `ACCEPT IDEA` / `APPROVE CODE COPYING` / `DEFER` / `REJECT` plus issue, version/milestone, tests, specific version/commit/notice and who authorized. Update this file through a reviewed PR and link the actual reviewer statements.
5. **User-facing releases** do not depend on two agents agreeing on unrelated experimental visual ideas; keep optional spikes out of the stable release's critical path unless accepted.

**Current decisions: 0 independently dual-reviewed, 0 source-code-copy approvals.** The author's provisional opinions here are not equivalent to accepted ADRs. `THIRD_PARTY_NOTICES.md` tracks **actual imported material**, while this file records proposed technology choices and debate.
